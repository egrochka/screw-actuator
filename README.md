# Dynamic actuator for POD-tribometer

This project aims at creating and configuring a dynamic loading actuator for a POD-tribometer test stand. The project parts uploaded here includs the code used, as well as the necesary parts in form of CAD models and drafts.

## About code

The project currently includes arduino source code for the actuator, as well as MATLAB code used to measure the output performance and calibrate the system.

## About CAD

The CAD models uploaded here include .par, .step and .stl variants of the models for ease of use and 3D-printing. All drafts are presented as .dft, .dwg, .dxf and .pdf. Drafts including _scaled are formated in 1:1 scale so they can be directly imported to Adobe Illustrator or whatever software for manufacturing.
